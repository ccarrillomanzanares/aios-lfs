v0.24.0 — 2026-09-12

↓ one ISO · 1.6 GB deb5610269ab34c8968838b54b088de7

features

  • One ISO. There is no longer a separate "with LLM" image: the same ISO carries the whole system and the local model is downloaded during setup (Qwen3.6-35B-A3B, 22.1 GB, no GPU needed). The image went from 7.3 GB to 1.6 GB.
  • The local/cloud choice covers every case. Both live mode and the disk installer ask the same question: run the model on your own computer, or use an external API. The hardware requirements are shown before downloading, together with a progress bar.
  • Much shorter first-run setup. What used to be ~18 questions is now ~8. Theme, voice, thinking and the date/time step are no longer asked: they are chat commands (/theme, /voice, /think) and the new aios-time command.
  • New aios-time command — timezone and NTP, the step that used to live inside the installer. Works interactively or as aios-time zone Europe/Madrid.

fixes

  • A wrong answer can no longer kick you out of the installer. Ten places were audited and fixed: _read_line span forever on EOF, an empty password was accepted and silently skipped by chpasswd (leaving the factory password on the installed disk), the disk selector cancelled after three bad answers, and a typo in the wipe confirmation aborted the installation. Now they re-ask, and cancelling is explicit.
  • Silent boot on the installed disk too: GRUB menu hidden and the console cursor off, as in live mode.
  • Real download of the AIOS local model — resumes if interrupted, verifies the size, and reports decimal units (22.1 GB).

v0.18.5 — 2026-09-07 20:21

↓ no LLM 6bade841ca07f8dda43d74efc93dbfc6 · with Qwen 4f7d0ed2a08cf647f1b92519facd05b7

features

  • Chromium + CDP (browser_*): new tools browser_navigate, browser_eval, browser_click, browser_type — real browser control via DevTools Protocol (real DOM, clicks by selector, forms by field). No more blind OCR. Chromium 152 installed from sven.
  • Browser prompt: the agent uses browser_* to browse (never process_send — browsers ignore stdin); documented workflow (navigate → eval → click → type).
  • Dynamic installer banner: aios-install reads the version from the CHANGELOG (shows AIOS LFS INSTALLER v0.18.5 instead of the hardcoded 1.1.3).

fixes

  • silent voice (root cause): the tic aplay holds the PCM device; TTS launched another aplay → Device or resource busy silenced. Fix: close/reopen the tic aplay INSIDE the _speak_sync thread (voice.py) — speak() spawns a thread and returns, so closing in chat.py reopened before TTS opened the device.
  • browser did not navigate: _ensure_browser() used _urlopen without importing it (silent NameError) in the check and in the wait loop → 10s timeout. Fix: urllib.request as _url in both + 30s wait (Chromium takes a while to start on the laptop).
  • aios-diag not executable: mode 100755 in git (the /usr/local/bin/aios-diag wrapper had no x).

v0.18.4 — 2026-09-07 15:58

↓ no LLM 6596430daaf3f71efd368d72645fda58 · with Qwen 023cd3eb772c2984e419f1f3189ba748

fixes

  • laptop boot (boot race): getty@tty1 launched X before udev applied permissions to /dev/dri/card0 → open /dev/dri/card0: Permission denied → no screens found → getty loop → start-limit-hit → blinking cursor with no session. aios-session now waits up to 30s for /dev/dri/card0 to be readable/writable before startx.
  • laptop audio (same race): audio-detect.py ran 9s into boot, when only the HDMI card was visible → wrote plughw:0,0 (HDMI) instead of the analog one. Now if the only detected card is HDMI, it waits and retries (up to 15s) until the analog card appears.
  • deploy: aios-deploy-and-build.sh now copies scripts/aios-session and scripts/audio-detect.py to the tree (they never reached the ISO before).

v0.18.3 — 2026-09-07 08:06

↓ no LLM 299e40cc6d6c5cd345310f46c0a7004a · with Qwen 7db111fd2eabb3e46809f7f00a16e910

fixes

  • timeout HTTP 120s → 300s: long generations on CPU (stories, long answers) exceeded the 120s limit and the agent cut with Read timed out.
  • compression summary as user (not system): the no-thinking model frob/qwen3.5-instruct:9b requires system at the start of the history; a summary inserted as system in the middle caused 500 Jinja Exception: System message must be at the beginning.
  • cloud compression threshold 20% → 10%: keeps prompt-eval (~25 tok/s on CPU) under the timeout with large contexts.
  • tool output cap: ANSI strip + truncation to 1200/1000 chars (was 5000/2000) — command outputs no longer bloat the context.
  • MAX_TURNS 10 → 25 + when exhausted the agent asks (continue) Aún no he terminado... ¿Quieres que continúe? instead of (no response).
  • procedural memory filter: no longer caches greetings/trivial queries, short answers (<80 chars) or (continue) status messages.
  • OCR eng+spa: tesseract with Spanish for Spanish pages.
  • bracketed paste in _read_line() (setup.py): copy/paste works in the API key prompt.
  • dynamic version banner: AIOS/v0.18.3 is read from the CHANGELOG (auto-updates with each release) instead of the hardcoded AIOS/1.4.
  • Wargames teletype tick: 4kHz transient + 250Hz body, half volume, --period-size=128 (tick per character, no bursts); the user-typing tick is removed (only the agent's typewriter sounds).

v0.18.2 — 2026-09-04 23:21

fixes

  • docker group not created on install: missing systemd ALPM hooks (20-systemd-sysusers etc.) — added to the tree; sven install docker now creates the docker group automatically.
  • docker socket not connecting: LFS symlinks /var/run → /run, /var/lock → /run/lock, /etc/mtab → /proc/self/mounts were missing (lost by an old mksquashfs over overlay) — recreated in tree and installed disks.
  • build hardening: aios-deploy-and-build.sh verifies/recreates the 3 LFS symlinks before every mksquashfs.

v0.18.1 — 2026-09-04 17:58

fixes

  • installer password bug (critical): getpass read passwords corruptly on a dirty raw terminal — replaced with a self-contained _read_password() that masks input and controls the tty directly.
  • installer chroot ordering bug (critical): cleanup_chroot() ran before set_passwords()/harden_* — reordered so it runs last, just before the final umount.
  • installer password — real root cause (PAM): /etc/pam.d/system-auth was truncated to a single line with no password stack — chpasswd never wrote to /etc/shadow. Restored the full BLFS system-auth.
  • agent anti-loop removed: the "3 identical tool calls" detector caused false positives — replaced with a simpler guard that only refuses to re-run a run_command that already failed.
  • sudo password asked inline: removed the /sudo round-trip; run_command prompts for the sudo password (masked) directly.
  • timezone selector: hierarchical picker (continent → region → city) integrated with NTP; persisted to disk on install.

v0.18 — 2026-08-31 19:48

↓ no LLM 76179b138ab6c706a3d7863222941193 · with Qwen 712edc7f0663069b18eded912fe327d6

new features

  • local LLM — Qwen3.5-9B: the bundled local model is now Qwen3.5-9B (Q4_K_M), replacing Qwen3-8B — better reasoning and tool calling. llama-server upgraded to b10655 (CPU-dispatched: runs on any x86-64, from SSE4.2 to AVX-512).

fixes

  • cloud empty responses: the Ollama Hardened server now serves qwen3.5:9b with a 32K context window (OLLAMA_CONTEXT_LENGTH=32768) instead of the 4K default — fixes empty responses where reasoning + tool-calling exhausted the context.
  • agent empty-response diagnostics: on an empty response the agent now reports the cause (finish_reason, reasoning characters emitted) instead of the generic "(empty model response)".

v0.16 — August 2026

↓ no LLM 2f6b6f898d68df17f1f988b572c50b5d · with Qwen 4a2e2ca255eab7c141c73b071f2519ce

voice (TTS/STT) — independent voice: section from chat

fixes

  • Beep/tic did not sound: aplay --buffer-size=512 --period-size=512 (buffer == period) failed silently on some codecs; removed. aios-diag now collects audio state.
