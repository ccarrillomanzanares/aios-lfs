Artificial Intelligence Operating System

Greetings, Professor Falken
AIOS is a minimalist operating system built with and for artificial intelligence — autonomous, yet always under human review.

The goal: a computer operated by a human–agent team, and a complete SRE platform.

Made with nostalgia for classic AI movies (WarGames · The Matrix · Tron · 2001 · Blade Runner)

Bootable ISO — run it in live mode, or install it to disk. Works on physical hardware and virtual machines (tested on VirtualBox).
