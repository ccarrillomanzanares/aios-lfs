AIOS keyboard shortcuts
========================

  Super+Return         Open a terminal
  F1/Super+F1          Show this shortcut list
  Super+q              Close the focused window
  Super+h/j/k/l        Move focus
  Super+Shift+h/j/k/l  Move the focused window
  Super+v              Split vertical
  Super+b              Split horizontal
  Super+f              Toggle fullscreen
  Super+s              Layout stacking
  Super+w              Layout tabbed
  Super+Shift+e        Exit i3 (back to login)
  Super+Print          Start/stop screen recording (/tmp/grabacion.mp4)

In the chat:
  SPACE                Skip the typewriter (write the pending text instantly)
  /sound               Toggle the typewriter sound
  /theme               Change the color theme
  /think               Toggle thinking mode (local model; more precise, slower)
  /reset               Clear the conversation
  /health              Show system status
  /stats               Show session stats (messages / tokens)
  exit                 Leave the chat

In this list: press q (or Super+q) to close.
(Super = the Windows key)
